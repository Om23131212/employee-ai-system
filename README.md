# Project Overview

The Employee AI Management System is designed to simplify employee management processes using modern web technologies and AI integration. The application allows administrators to securely manage employee information, monitor performance metrics, and generate intelligent AI-based recommendations using OpenRouter AI APIs.

The project is built using the MERN Stack:

- MongoDB for database management
- Express.js for backend APIs
- React.js for frontend UI
- Node.js for server-side development
